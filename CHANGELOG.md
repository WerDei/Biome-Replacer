# Important information
If you used Biome replacer prior to this version (3.0), **your world can become corrupted**
after updating it to Minecraft 26.1. Please read this page explaining what this means and how to recover it:  
https://github.com/WerDei/Biome-Replacer/blob/master/docs/RECOVERY-26.1.md  
This was an honest mistake that simply went unnoticed. I am very sorry for the trouble!

Full changelog:
- Added Minecraft 26.1 and 26.2 support
- Fixed world corruption when updating to 26.1+
- "Experimental features" popup no longer shows up when opening the world
- Blueprint integration fixes and performance improvements
